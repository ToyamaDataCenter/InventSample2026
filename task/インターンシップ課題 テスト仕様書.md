# 3. 総合テスト

## SYS-001 正常系業務シナリオ

### 手順

1. 品名入力
2. 数量入力
3. 追加ボタン押下
4. 登録ボタン押下
5. 確認画面で検索

### 期待結果

- エラーなし

- 在庫数が正しく表示される
